# Manual Didático — Aprenda Tapi

Curso introdutório. 10 lições. Cada lição: vocabulário + gramática + exercícios.

---

## Lição 1 — Pronúncia e cumprimento

### Sons
Tapi usa 9 letras: `a, i, u, k, m, n, p, s, t`. Cada letra = um som. Sem exceções.

| Letra | Som como em |
|-------|-------------|
| a | "casa" |
| i | "vida" |
| u | "luz" |
| k | "casa" |
| m | "mão" |
| n | "não" |
| p | "pé" |
| s | "sol" |
| t | "tá" |

### Regra de acento
Sempre na penúltima sílaba: ka**ma**, pa**ti**, ta**pi**.

### Vocabulário
| Tapi | Português |
|------|-----------|
| na | olá (vocativo) |
| tina | bom |
| muka | mau |
| mi | eu |
| tu | tu/você |

### Frases
- `na, tu` = "olá, tu"
- `mi tina` = "estou bem"
- `tu tina ku` = "tu estás bem?"

### Exercícios
1. Pronuncie: `mati-mati`, `tunu-puka`, `kapa-kupa`.
2. Traduza: "tu estás mau?"
3. Resposta: `tu muka ku`

## Lição 2 — Eu, tu, ele

### Vocabulário
| Tapi | Português |
|------|-----------|
| si | ele/ela |
| nupi | nós |
| mupi | vós |
| kupi | eles/elas |
| ipa | ser/estar |
| ku | (partícula de pergunta) |
| pa | não |

### Gramática
Frase simples: `SUJEITO + VERBO + COMPLEMENTO`.

Cópula `ipa` para identidade:
- `mi ipa mati-mati` = "sou pessoa"
- `tu ipa papu` = "és homem"

Negação com `pa` antes do verbo:
- `mi pa ipa muka` = "não sou mau"

### Exercícios
1. "Ele é bom" → `si ipa tina`
2. "Nós não somos maus" → `nupi pa ipa muka`
3. "Eles são pessoas?" → `kupi ipa mati-mati ku`

## Lição 3 — Casa, terra, água, fogo

### Vocabulário (4 elementos)
| Tapi | Português |
|------|-----------|
| kama | casa |
| tana | terra |
| mina | água |
| puka | fogo |
| nita | ar |
| tunu | sol |
| pinu | lua |

### Posse com `ni`
Estrutura: `possuidor + ni + possuído`.
- `mi ni kama` = "minha casa"
- `tu ni mina` = "tua água"
- `papi ni puka` = "fogo do pai"

### Exercícios
1. "Casa do sol" → `tunu ni kama`
2. "Nossa terra" → `nupi ni tana`

## Lição 4 — Verbos básicos (presente)

### Vocabulário
| Tapi | Português |
|------|-----------|
| mani | comer |
| piku | beber |
| tika | ver |
| sina | ouvir |
| taka | falar |
| ina | ir |
| una | vir |

### Estrutura
- `mi mani` = "eu como"
- `tu piku mina` = "você bebe água"
- `si tika kama` = "ele vê a casa"

Verbos sem flexão para pessoa.

### Exercícios
1. "Nós ouvimos a voz" → `nupi sina tama`
2. "Eles vão à casa" → `kupi ina kama`

## Lição 5 — Passado e futuro

### Sufixos
| Tempo | Sufixo | Exemplo |
|-------|--------|---------|
| Presente | (nenhum) | `mani` (come) |
| Passado | -ta | `manita` (comeu) |
| Futuro | -ka | `manika` (comerá) |

### Frases
- `mi tikata si` = "eu vi ele"
- `tu inaka kama` = "você irá à casa"
- `nupi takata-ta pami` = aspectos compostos (cobre Lição 8)

### Exercícios
1. "Choveu" → `masuta` (chuva-PASS, usando "masu" como verbo)
2. "Ele beberá água" → `si pikuka mina`

## Lição 6 — Demonstrativos

### Vocabulário
| Tapi | Português |
|------|-----------|
| mata | este |
| mati | esse |
| maku | aquele |
| muta | aqui |
| muki | aí |
| muna | ali |

### Frases
- `mata kama` = "esta casa"
- `mi ipa muta` = "estou aqui"
- `maku mati-mati ipa muna` = "aquela pessoa está ali"

### Exercícios
1. "Essa água é boa" → `mati mina ipa tina`
2. "Aquela árvore é grande" → `maku tipa ipa tipi`

## Lição 7 — Interrogativos

### Vocabulário
| Tapi | Português |
|------|-----------|
| nima | quem |
| nipi | o que |
| nika | onde |
| niku | quando |
| napa | quanto |
| nima-pa | como |
| nima-tu | por que |

### Estrutura
Interrogativo *in situ* + `ku` no fim (opcional).

- `nima ipa muta ku` = "quem está aqui?"
- `tu mani nipi ku` = "que tu come?"
- `kupi inaka nika ku` = "aonde eles irão?"

### Exercícios
1. "Quando vieste?" → `tu unata niku ku`
2. "Como sabes?" → `tu kima nima-pa ku`

## Lição 8 — Aspectos verbais

### Sufixos (vão depois do tempo)
| Aspecto | Sufixo | Significado |
|---------|--------|-------------|
| Habitual | -sa | costuma X |
| Progressivo | -ma | está X-ndo |
| Perfectivo | -pa | acabou de X |

Combinações:
- `manisa` = costuma comer
- `manima` = está comendo
- `manipa` = acabou de comer
- `manitasa` = costumava comer
- `manikamap` = (FUT+PROG não usual; combinar é livre)

### Exercícios
1. "Estou indo" → `mi inama`
2. "Tu sempre dormes" → `tu napisa`
3. "Ele tinha acabado de falar" → `si takatapa`

## Lição 9 — Modais e cláusulas relativas

### Modais
| Tapi | Português |
|------|-----------|
| puni | poder |
| mika | dever |
| naki | querer |

Estrutura: `MODAL + VERBO-PRINCIPAL`. Tempo no modal.
- `mi puni mani` = "posso comer"
- `tu mikata ina` = "tu devias ir"
- `si nakika tika nupi` = "ele vai querer ver-nos"

### Relativas
`ta` = "que" (relativo).

- `mati-mati ta unata` = "pessoa que veio"
- `kama ta mi mipa` = "casa onde moro"
- `tama ta tu takata` = "palavra que disseste"

### Exercícios
1. "Posso ver" → `mi puni tika`
2. "A criança que dorme" → `kuni ta napi`

## Lição 10 — Composição (a alma do Tapi)

### Princípio
Palavras complexas = raízes simples coladas com hífen.

Exemplos clássicos:
- `tunu-puka` = sol-fogo = calor
- `pumu-tipi` = coração-grande = coragem
- `kama-titu` = casa-asa = avião
- `tama-pami` = palavra-longa = telefone
- `kima-puna` = saber-dar = professor

### Crie suas palavras
Combine raízes para formar conceitos. Falantes entendem por contexto.

Exemplo: "saudade" não tem palavra direta. Possíveis compostos:
- `pumu-kuti` = coração-volta
- `pita-pami` = pensamento-longo
- `kapa-pa` = tempo-negação

### Exercício final
Traduza para Tapi, usando compostos:
1. "Bicicleta" → `mana-puta` (redondo-pé)
2. "Hospital" → `puti-tina-kama` (corpo-bom-casa) ou `naka-kama`
3. "Felicidade" → `pumu-tina`
4. "Aeroporto" → `kama-titu-kama` (avião-casa)
