# Manual Didático — Aprenda Tapi

Curso completo. 20 lições. Cada lição: vocabulário + gramática + exercícios.

**Lições 1-10**: básico (pronúncia → composição).
**Lições 11-20**: intermediário (causativo, voz, evidencialidade, honoríficos, subordinação, comparativo, numerais avançados, calendário, conversação, criação de palavras).

---

## Lição 1 — Pronúncia e cumprimento

### Sons
Tapi usa 9 letras: `a, i, u, k, m, n, p, s, t`. Cada letra = um som. Sem exceções.

| Letra | Som como em |
|-------|-------------|
| a | "casa" |
| i | "vida" |
| u | "luz" |
| k | "casa" |
| m | "mão" |
| n | "não" |
| p | "pé" |
| s | "sol" |
| t | "tá" |

### Regra de acento
Sempre na penúltima sílaba: ka**ma**, pa**ti**, ta**pi**.

### Vocabulário
| Tapi | Português |
|------|-----------|
| na | olá (vocativo) |
| tina | bom |
| muka | mau |
| mi | eu |
| tu | tu/você |

### Frases
- `na, tu` = "olá, tu"
- `mi tina` = "estou bem"
- `tu tina ku` = "tu estás bem?"

### Exercícios
1. Pronuncie: `mati-mati`, `tunu-puka`, `kapa-kupa`.
2. Traduza: "tu estás mau?"
3. Resposta: `tu muka ku`

## Lição 2 — Eu, tu, ele

### Vocabulário
| Tapi | Português |
|------|-----------|
| si | ele/ela |
| nupi | nós |
| mupi | vós |
| kupi | eles/elas |
| ipa | ser/estar |
| ku | (partícula de pergunta) |
| pa | não |

### Gramática
Frase simples: `SUJEITO + VERBO + COMPLEMENTO`.

Cópula `ipa` para identidade:
- `mi ipa mati-mati` = "sou pessoa"
- `tu ipa papu` = "és homem"

Negação com `pa` antes do verbo:
- `mi pa ipa muka` = "não sou mau"

### Exercícios
1. "Ele é bom" → `si ipa tina`
2. "Nós não somos maus" → `nupi pa ipa muka`
3. "Eles são pessoas?" → `kupi ipa mati-mati ku`

## Lição 3 — Casa, terra, água, fogo

### Vocabulário (4 elementos)
| Tapi | Português |
|------|-----------|
| kama | casa |
| tana | terra |
| mina | água |
| puka | fogo |
| nita | ar |
| tunu | sol |
| pinu | lua |

### Posse com `ni`
Estrutura: `possuidor + ni + possuído`.
- `mi ni kama` = "minha casa"
- `tu ni mina` = "tua água"
- `papi ni puka` = "fogo do pai"

### Exercícios
1. "Casa do sol" → `tunu ni kama`
2. "Nossa terra" → `nupi ni tana`

## Lição 4 — Verbos básicos (presente)

### Vocabulário
| Tapi | Português |
|------|-----------|
| mani | comer |
| piku | beber |
| tika | ver |
| sina | ouvir |
| taka | falar |
| ina | ir |
| una | vir |

### Estrutura
- `mi mani` = "eu como"
- `tu piku mina` = "você bebe água"
- `si tika kama` = "ele vê a casa"

Verbos sem flexão para pessoa.

### Exercícios
1. "Nós ouvimos a voz" → `nupi sina tama`
2. "Eles vão à casa" → `kupi ina kama`

## Lição 5 — Passado e futuro

### Sufixos
| Tempo | Sufixo | Exemplo |
|-------|--------|---------|
| Presente | (nenhum) | `mani` (come) |
| Passado | -ta | `manita` (comeu) |
| Futuro | -ka | `manika` (comerá) |

### Frases
- `mi tikata si` = "eu vi ele"
- `tu inaka kama` = "você irá à casa"
- `nupi takata-ta pami` = aspectos compostos (cobre Lição 8)

### Exercícios
1. "Choveu" → `masuta` (chuva-PASS, usando "masu" como verbo)
2. "Ele beberá água" → `si pikuka mina`

## Lição 7 — Interrogativos

### Vocabulário
| Tapi | Português |
|------|-----------|
| nima | quem |
| nipi | o que |
| nika | onde |
| niku | quando |
| napa | quanto |
| nima-pa | como |
| nima-tu | por que |

### Estrutura
Interrogativo *in situ* + `ku` no fim (opcional).

- `nima ipa muta ku` = "quem está aqui?"
- `tu mani nipi ku` = "que tu come?"
- `kupi inaka nika ku` = "aonde eles irão?"

### Exercícios
1. "Quando vieste?" → `tu unata niku ku`
2. "Como sabes?" → `tu kima nima-pa ku`

## Lição 8 — Aspectos verbais

### Sufixos (vão depois do tempo)
| Aspecto | Sufixo | Significado |
|---------|--------|-------------|
| Habitual | -sa | costuma X |
| Progressivo | -ma | está X-ndo |
| Perfectivo | -pa | acabou de X |

Combinações:
- `manisa` = costuma comer
- `manima` = está comendo
- `manipa` = acabou de comer
- `manitasa` = costumava comer
- `manikamap` = (FUT+PROG não usual; combinar é livre)

### Exercícios
1. "Estou indo" → `mi inama`
2. "Tu sempre dormes" → `tu napisa`
3. "Ele tinha acabado de falar" → `si takatapa`

## Lição 9 — Modais e cláusulas relativas

### Modais
| Tapi | Português |
|------|-----------|
| puni | poder |
| mika | dever |
| naki | querer |

Estrutura: `MODAL + VERBO-PRINCIPAL`. Tempo no modal.
- `mi puni mani` = "posso comer"
- `tu mikata ina` = "tu devias ir"
- `si nakika tika nupi` = "ele vai querer ver-nos"

### Relativas
`ta` = "que" (relativo).

- `mati-mati ta unata` = "pessoa que veio"
- `kama ta mi mipa` = "casa onde moro"
- `tama ta tu takata` = "palavra que disseste"

### Exercícios
1. "Posso ver" → `mi puni tika`
2. "A criança que dorme" → `kuni ta napi`

## Lição 10 — Composição (a alma do Tapi)

### Princípio
Palavras complexas = raízes simples coladas com hífen.

Exemplos clássicos:
- `tunu-puka` = sol-fogo = calor
- `pumu-tipi` = coração-grande = coragem
- `kama-titu` = casa-asa = avião
- `tama-pami` = palavra-longa = telefone
- `kima-puna` = saber-dar = professor

### Crie suas palavras
Combine raízes para formar conceitos. Falantes entendem por contexto.

Exemplo: "saudade" não tem palavra direta. Possíveis compostos:
- `pumu-kuti` = coração-volta
- `pita-pami` = pensamento-longo
- `kapa-pa` = tempo-negação

### Exercício final
Traduza para Tapi, usando compostos:
1. "Bicicleta" → `mana-puta` (redondo-pé)
2. "Hospital" → `puti-tina-kama` (corpo-bom-casa) ou `naka-kama`
3. "Felicidade" → `pumu-tina`
4. "Aeroporto" → `kama-titu-kama` (avião-casa)

## Lição 11 — Causativo

Causativo = "fazer X-er". Em Tapi: `patu` (fazer) + verbo.

### Estrutura
`SUJ + patu + ALVO + VERBO`.

- `mi patu si mani` = "fiz ele comer"
- `mama patu kuni napi` = "mãe faz filho dormir"
- `kima-puna patu mati-mati kima` = "professor faz pessoa saber" (= ensina)

Tempo no verbo `patu`, não no principal:
- `mi patuta si mani` = "fiz ele comer (ontem)"
- `tu patuka kuni napi` = "tu farás filho dormir"

### Vocabulário
| Tapi | Português |
|------|-----------|
| patu | fazer (causativo) |
| sika | matar (= patu kina, mas raiz curta) |
| mika-patu | obrigar (lit. dever-fazer) |

### Exercícios
1. "Eles me fizeram rir" → `kupi patuta mi tasi`
2. "A chuva fará a planta crescer" → `masu patuka kipi tipi`

## Lição 12 — Voz passiva

Inverte sujeito e objeto. Partícula `mu` marca agente.

### Estrutura
`OBJETO + VERBO + mu + AGENTE`.

- `kasi manita mu si` = "comida foi comida por ele"
- `tama-naku patuta-tama mu mati-mati matu` = "livro foi escrito por muitas pessoas"

Comparar:
- Ativa: `si mani kasi` = "ele come a comida"
- Passiva: `kasi mani-pa mu si` = "a comida está comida por ele"

### Agente desconhecido
Sem `mu`: passiva impessoal.
- `kama patuta` = "a casa foi feita" (por alguém não dito)

### Exercícios
1. "Suanu foi visto pela mãe" → `Suanu tikata mu mama`
2. "A árvore foi cortada" → `tipa sasita`

## Lição 13 — Evidencialidade

Marca **como você sabe** do que fala. Anexa-se ao verbo (geralmente no passado).

| Sufixo | Significado | Exemplo |
|--------|-------------|---------|
| ∅ (nada) | Vi/vivi diretamente | `manita` (comeu, eu vi) |
| `-ni` | Inferi por evidência | `manita-ni` (devia ter comido — vi os pratos sujos) |
| `-ni-ni` | Me contaram | `manita-ni-ni` (disseram que comeu) |
| `-ni-ku` | Duvido | `manita-ni-ku` (talvez tenha comido, não sei) |

### Quando usar
- Notícias: `-ni-ni` (reportado)
- Boato: `-ni-ku` (duvidoso)
- Investigação: `-ni` (inferência)
- Testemunho direto: ∅

### Vocabulário
| Tapi | Português |
|------|-----------|
| muta-ka | verdade |
| muta-ka-pa | mentira (lit. verdade-NEG) |
| tika | ver (raiz da evidência direta) |

### Exercícios
1. "Dizem que choveu" → `masuta-ni-ni`
2. "Talvez tenha vindo" → `unata-ni-ku`
3. "Vi que dormiu" → `napita`

## Lição 14 — Honoríficos

Registros formais. Tapi usa sufixos e formas dedicadas.

### Pronomes formais
- `tu-sami` = você (formal, lit. tu-superior)
- `mi-puku` = eu (humilde, lit. eu-pequeno)
- `papi-sami` = senhor (lit. pai-superior)
- `mama-sami` = senhora (lit. mãe-superior)

### Sufixo de respeito `-sami`
Adicionado a substantivos sociais:
- `kima-puna-sami` = professor (respeitoso)
- `miti-mati-sami` = chefe (respeitoso)

### Vocativo formal
`na, papi-sami` = "Senhor, ..."
`na, mama-sami` = "Senhora, ..."

### Quando usar
- Primeira interação com estranho mais velho
- Contexto profissional formal
- Cerimônias
- Texto escrito formal (cartas, declarações)

Entre íntimos ou pares: forma simples.

### Exercícios
1. "Bom dia, senhora" → `tunu-una tina, mama-sami`
2. "Eu, humildemente, agradeço" → `mi-puku taka-tina sami`

## Lição 15 — Subordinação

Conjunções subordinadas combinam orações.

| Tapi | Significado | Exemplo |
|------|-------------|---------|
| `asi` | se (condicional) | `asi tu una, mi tasi` (se vieres, eu rio) |
| `miku` | porque | `mi tasi miku tu una` (rio porque vieste) |
| `upa` | quando (geral) | `upa masu, mi mipa kama` (quando chove, fico em casa) |
| `pamu` | enquanto | `pamu tu napi, mi patu` (enquanto dormes, eu trabalho) |
| `ta` | que (relativo) | `mati ta una` (pessoa que veio) |

### Concordância de tempo
Tempo só na oração principal — subordinada herda contexto.
- `asi masuta, mi pa inata` = "se choveu, não fui"
- `upa tu unata, mi napita` = "quando vieste, eu dormia"

### Causa contra-factual
`asi pa X, Y` = "se não fosse X, Y".
- `asi pa tu, mi sika` = "se não fosses tu, eu morreria"

### Exercícios
1. "Comerei se tiver comida" → `mi manika asi mi nuta kasi`
2. "Falo porque sei" → `mi taka miku mi kima`
3. "Estudo enquanto chove" → `mi kima-kapa pamu masu`

## Lição 16 — Comparativo e superlativo

### Comparativo `sa`
`X sa Y` = "X mais que Y".

- `mata kama tipi sa mati` = "esta casa é maior que essa"
- `mi sipa kana sa tu` = "ando mais longe que tu"

Inverso: usar `pa-sa`.
- `mi puku pa-sa tu` = "sou menor que tu" (lit. menor "menos-que" tu)

### Superlativo `sami`
Adicionado ao adjetivo.

- `tipi sami` = "o maior"
- `panu sami ni puma` = "o mais belo da floresta"

### Igualdade `tani-tani`
- `mi tani-tani tu mipi tipi` = "sou igual a ti em tamanho"

### Vocabulário
| Tapi | Português |
|------|-----------|
| sa | comparativo (mais) |
| pa-sa | menos (composto) |
| sami | superlativo |
| tani-tani | igual |

### Exercícios
1. "Mais doce que mel" → `suma sa muma-mina-kuma`
2. "O mais forte do mundo" → `musu-tipi sami ni nuki`
3. "Igual ao pai" → `tani-tani papi`

## Lição 17 — Numerais avançados

### Cardinal
| Tapi | Número |
|------|--------|
| pa-tani | 0 |
| tani | 1 |
| pi | 2 |
| ti | 3 |
| pu | 4 |
| ka | 5 |
| ma | 6 |
| nuku | 7 |
| nu | 8 |
| pina | 9 |
| nuna | 10 |
| nuna-tani | 11 |
| nuna-pi | 12 |
| pi-nuna | 20 |
| pi-nuna-tani | 21 |
| ti-nuna | 30 |
| kuna | 100 |
| kuna-nuna | 1000 |

Composto: `dezena-unidade`. Ex.: `pi-nuna-ka` = 25.

### Ordinal (`ku-`)
- `ku-tani` = primeiro
- `ku-pi` = segundo
- `ku-ti` = terceiro
- `ku-nuna` = décimo

### Fração `X-ni-Y`
"X de Y" = X partes de Y.
- `tani-ni-pi` = um meio (1/2)
- `tani-ni-pu` = um quarto (1/4)
- `ti-ni-ka` = três quintos (3/5)

### Multiplicação `X-kapa`
"X vezes" = X-tempos.
- `pi-kapa` = duas vezes
- `nuna-kapa` = dez vezes

### Exercícios
1. "Terceiro filho" → `ku-ti kuni`
2. "Meio quilo" (½) → `tani-ni-pi`
3. "Cinco vezes ao dia" → `ka-kapa pasi nupa`

## Lição 19 — Conversação prática

### Cumprimentos
- `na!` = oi (vocativo)
- `tu tina ku` = está bem?
- `tina-tina` = bem, obrigado
- `mata-pa` = como vai (lit. assim-modo)

### Apresentação
- `mi ipa [nome]` = sou [nome]
- `tu ku` = e tu?
- `tina supa tu` = bom te conhecer

### Pedidos
- `mi naki ...` = quero ...
- `tu puni ... ku` = podes ...?
- `puna-ti ...` = dá ...

### Agradecimento e desculpas
- `tina-tina` = obrigado
- `tina-tina sami` = muito obrigado
- `pa-mata` = de nada
- `taka-muku` = desculpa (lit. dizer-divisão)

### Despedidas
- `ina tina` = vai bem
- `kuti tina` = boa volta
- `tika kuti` = até logo (lit. ver-de-novo)
- `kapa-kapa tina` = sempre bem

### Diálogo modelo (turista)
```
Tu:   na! mi pa kima nani. tu puni ama-puna mi ku?
Você: Olá! Não sei o caminho. Podes me ajudar?

Si:   mata-ipa. tu ina nika ku?
Ele:  Claro. Para onde vais?

Tu:   mi ina ipa-tipi-kama.
Você: Vou ao hospital.

Si:   ina-ti pasi nani-tipi mata, samu pasi ku-ti pinu-kapa.
Ele:  Vai pela rua principal, direita na terceira esquina.

Tu:   tina-tina sami!
Você: Muito obrigado!
```

### Exercícios
1. Apresente-se em Tapi.
2. Peça uma indicação de caminho.
3. Despeça-se de três maneiras diferentes.

## Lição 20 — Criar palavras novas

Tapi é **vivo na composição**. Quando uma palavra falta, você compõe.

### Princípios
1. **Use raízes existentes** antes de inventar
2. **Hífen** entre componentes
3. **Significado literal** deve sugerir o conceito
4. **Comprimento aceitável**: 2-5 componentes
5. **Contexto** completa o resto

### Padrões frequentes
| Padrão | Exemplo | Tradução |
|--------|---------|----------|
| objeto-função | `tama-naku` (palavra-raiz) | livro |
| material-forma | `mapu-mana` (pedra-redonda) | bola de pedra |
| ação-objeto | `mani-kasi` (comer-comida) | refeição |
| qualidade-coisa | `tipi-mina` (grande-água) | oceano |
| órgão-ação | `pati-tika` (olho-ver) | foto |
| lugar-coisa | `kama-tunu` (casa-sol) | varanda ensolarada |

### Exemplos de criação
- "Saudade" → `pumu-kana` (coração + longe)
- "Internet" → `tama-kupa` (palavra + tudo)
- "Inteligência artificial" → `patu-pita` (feito + pensar)
- "Selfie" → `pati-tika-ku` (foto + reflexivo)
- "Podcast" → `tama-na-tama-kupa` (canção + internet, ou tama-pami-kuta = palavra-longa-pegar)
- "Burnout" → `puti-kupa-pa` (corpo-todo-NEG)

### Exercício final
Crie palavras Tapi para:
1. **Geladeira** → ?
2. **Algoritmo** → ?
3. **Aniversário** → ?
4. **Espelho** → ?
5. **Saudade do futuro** → ?

(Propostas: `kasi-kama-pini` / `kupu-mapu-pita` / `nupa-sasu-kapa` / `pati-mapu` / `pumu-nupa-maku-ka`)

Compartilhe suas criações com a comunidade.
