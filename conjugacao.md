# Tabela Completa de Conjugação Verbal — Tapi

Verbo modelo: **`ama`** (amar)

## Conjugação por tempo (sem aspecto)

| Tempo    | Sufixo | Forma  | Tradução       |
|----------|--------|--------|----------------|
| Presente | (∅)    | ama    | ama            |
| Passado  | -ta    | amata  | amou           |
| Futuro   | -ka    | amaka  | amará          |

Sem flexão de pessoa. `mi ama / tu ama / si ama` — todos usam `ama`.

## Por aspecto (sem tempo composto)

| Aspecto      | Sufixo | Forma  | Tradução               |
|--------------|--------|--------|------------------------|
| Simples      | (∅)    | ama    | ama                    |
| Habitual     | -sa    | amasa  | costuma amar           |
| Progressivo  | -ma    | amama  | está amando            |
| Perfectivo   | -pa    | amapa  | acabou de amar         |

## Combinações tempo + aspecto

| Tempo + Aspecto         | Forma     | Tradução                              |
|-------------------------|-----------|---------------------------------------|
| Pres + Habitual         | amasa     | costuma amar                          |
| Pres + Progressivo      | amama     | está amando                           |
| Pres + Perfectivo       | amapa     | acabou de amar                        |
| Pass + Habitual         | amatasa   | costumava amar                        |
| Pass + Progressivo      | amatama   | estava amando                         |
| Pass + Perfectivo       | amatapa   | tinha acabado de amar (mais-que-perf) |
| Fut + Habitual          | amakasa   | há de costumar amar                   |
| Fut + Progressivo       | amakama   | estará amando                         |
| Fut + Perfectivo        | amakapa   | terá acabado de amar (fut. perfeito)  |

## Modos / vozes

### Imperativo
Sufixo `-ti`, sem sujeito explícito.
- `ama-ti` = ama!
- `pa ama-ti` = não ames!

### Passiva
Inversão O–S–V + `mu` antes do agente:
- Ativa: `mi ama tu` = "amo você"
- Passiva: `tu mi mu ama` = "você é amado por mim"

Com tempo:
- `tu mi mu amata` = "foste amado por mim"

### Reflexivo
Verbo + pronome reflexivo `-ku`:
- `mi ama mi-ku` = "amo-me"
- Variante média: `mi ama-ku` = "amo-me" (forma reduzida, voz média)

### Recíproco
Partícula `tatu` antes do verbo:
- `nupi tatu ama` = "nós nos amamos (mutuamente)"

### Causativo
Partícula `paki` antes do verbo:
- `mi paki ama si tu` = "faço-o amar você"

### Frequentativo
Reduplicação parcial:
- `ama-ama` = ama vez-em-quando / ama repetidamente

### Inceptivo
Partícula `supa`:
- `mi supa ama` = "começo a amar"

### Cessativo
Partícula `sutu`:
- `mi sutu ama` = "paro de amar"

### Continuativo
Partícula `mipa`:
- `mi mipa ama` = "continuo amando"

## Evidencialidade (sufixo após tudo)

| Sufixo evid. | Forma sobre `amata` | Significado |
|--------------|---------------------|-------------|
| (∅)          | amata               | amou (sei) |
| -ni          | amata-ni            | (infiro que) amou |
| -ni-ni       | amata-ni-ni         | dizem que amou |
| -ni-ku       | amata-ni-ku         | supostamente amou (duvidoso) |

## Estrutura geral de slots

```
RAIZ + TEMPO + ASPECTO + EVIDENCIALIDADE
```

Exemplo máximo:
- `amatapa-ni-ni` = "dizem que tinha acabado de amar"
  - ama (raiz) + ta (pass) + pa (perf) + ni-ni (reportado)

## Verbos modais — flexão própria

Modais conjugam normalmente como verbos plenos.

| Modal | Pres | Pass    | Fut     |
|-------|------|---------|---------|
| puni (poder)  | puni  | punita  | punika  |
| mika (dever)  | mika  | mikata  | mikaka  |
| naki (querer) | naki  | nakita  | nakika  |

Verbo principal fica em **forma base** (sem sufixos):
- `mi punita ama` = "pude amar"
- `tu mikaka tika` = "deverás ver"
- `si nakitama tika` = "estava querendo ver"

## Verbo cópula `ipa`

Conjuga como verbo normal.

| Forma   | Significado |
|---------|-------------|
| ipa     | é / está    |
| ipata   | foi / estava |
| ipaka   | será / estará |
| ipama   | está sendo  |
| ipapa   | acabou de ser |
| ipatasa | costumava ser |

## Resumo visual

```
[NEG?] [MODAL?] [INCEPTIVO/CESSATIVO/CONTINUATIVO?] [RAIZ][-tempo][-aspecto][-evidencialidade]
```

Exemplo complexo:
```
mi  pa   puni    supa    ama-ta-pa-ni-ni     tu
1SG NEG  poder   começ.  amar.PASS.PERF.REP   2SG
"Eu não pude começar a (ter acabado de) amar você — dizem"
```
