# Tapi — Cartão de Referência Rápida

**1 página. Tudo essencial.**

## Sons (9 letras)

```
Vogais:    a    i    u
Cons.:     p t k m n s
```

Acento: **penúltima sílaba**.

## Pronomes

| | Sing | Plural |
|-|------|--------|
| 1ª | mi | nupi |
| 2ª | tu | mupi |
| 3ª | si | kupi |

## Partículas

| | |
|-|-|
| `ni` posse | `mu` agente passivo |
| `pa` negação | `ku` pergunta |
| `na` vocativo | `sa` comparativo |
| `sami` superlativo | `tatu` recíproco |
| `ta` relativo (que) | `i` e |
| `a` ou | `asi` se |
| `miku` porque | `upa` quando |

## Sufixos verbais

| Tempo | Aspecto |
|-------|---------|
| -ta passado | -sa habitual |
| -ka futuro | -ma progressivo |
| (∅) presente | -pa perfectivo |

Imperativo: **-ti**. Reflexivo (em pronome): **-ku**.

## Numerais

```
1 tani   2 pi    3 ti    4 pu    5 ka
6 ma     7 nuku  8 nu    9 pina  10 nuna
100 kuna   1000 kuna-nuna
```

Ordinais: `ku-` + numeral. Composição: dezena+unidade (`nuna-tani`=11).

## Ordem das palavras

```
SUJEITO + (NEG?) + (MODAL?) + VERBO-tempo-aspecto + OBJETO + (PERGUNTA?)
```

Adjetivo **após** substantivo. Numeral **antes**. Demonstrativo **antes**.

## Cópula

`ipa` (ser/estar) — obrigatório com nome + locativo, opcional com adjetivo.

## Composição

`raiz1-raiz2` (hífen). Acento na última raiz.

Exemplos:
- `tunu-puka` = sol-fogo = calor
- `kama-titu` = casa-asa = avião
- `kima-puna` = saber-dar = professor

## Frases-modelo

```
mi ipa Chen                   "sou Chen"
tu tika nipi ku               "que tu vês?"
si pa unata                   "ele não veio"
nupi mani-ti muta             "comamos aqui!"
mata kama panu ipa tipi       "esta casa bela é grande"
```
